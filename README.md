# A股基本面多因子研究

## 项目背景

本项目基于 JQData 数据，构建沪深300基本面多因子研究框架，用于展示从数据获取、因子构建、因子检验到组合回测的基础量化研究流程。研究对象为沪深300历史成分股，采用月频调仓方式。

项目刻意保持简单、可解释：不使用机器学习模型、行业中性化或复杂的权重优化，适合金融专业校招作品展示。

## 研究流程

```text
JQData原始数据
  → 数据检查与清洗
  → 因子构建、MAD去极值、Z-score标准化
  → 计算未来一个月收益
  → Rank IC分析与单因子五分组回测
  → 三因子等权合成
  → 选取最高20%股票等权组合回测
  → 换手率与交易成本模拟
  → 使用 JQData 获取沪深300指数月末收盘价并进行基准比较
  → 输出绩效指标和图表
```

## 因子逻辑

| 类别 | 因子 | 含义 | 预期方向 |
| --- | --- | --- | --- |
| 价值 | EP = 1 / PE | 价值因子。PE 越低，EP 越高，通常代表估值更便宜 | 越高越好 |
| 质量 | ROE | 盈利质量因子。净资产收益率反映企业使用股东资本创造利润的能力 | 越高越好 |
| 成长 | revenue_growth | 成长因子。营业收入同比增长率反映企业收入扩张情况 | 越高越好 |

三个因子方向均统一为“因子值越高，预期未来收益越高”。

## 方法说明

- 股票池：沪深300历史成分股，避免直接用当前成分股代替历史股票池。
- 调仓频率：月频，每月最后一个交易日计算因子并持有至下月月末。
- 数据清洗：PE 小于等于零时无法计算 EP，因此设为缺失并删除该股票当期记录；其余无法计算因子的缺失记录同样删除。
- 因子处理：每个调仓日横截面内使用 MAD 方法去极值，再进行 Z-score 标准化。
- 因子检验：以 Spearman 相关系数计算 Rank IC，统计 IC 均值、标准差、ICIR 与正 IC 比例。
- 分组回测：每个单因子从低到高分为五组，组内等权，观察累计净值是否具有单调性。
- 多因子组合：`score = (EP_z + ROE_z + revenue_growth_z) / 3`，每月持有综合得分最高的 20% 股票并等权配置。
- 交易成本：按目标持仓权重的变化计算月度换手率，以 `0.1% × 换手率` 扣减当期收益。
- 绩效指标：累计收益、年化收益率、年化波动率、年化夏普比率（无风险利率暂设为 0）、最大回撤和平均月换手率。
- 基准比较：使用 JQData 的 `get_price()` 获取研究区间内沪深300指数月末收盘价，计算基准、超额收益、信息比率和超额最大回撤；接口无数据或权限不足时停止并报错。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `data_fetch.py` | 从 JQData 下载沪深300历史成分、月末价格与基本面数据 |
| `data_check.py` | 检查原始数据量、日期、重复值、缺失值和极端值 |
| `data_cleaner.py` | 清洗无效 PE 与无法计算因子的记录 |
| `factor_process.py` | 构造 EP，完成 MAD 去极值和横截面标准化 |
| `return_calculator.py` | 计算未来一个月收益率 |
| `ic_analysis.py` | 输出 Rank IC 月度序列和汇总指标 |
| `backtest_group.py` | 输出单因子五分组月收益和累计净值 |
| `multifactor.py` | 构造等权多因子得分与最高20%选股结果 |
| `turnover_calculator.py` | 根据相邻调仓日的等权持仓变化计算换手率 |
| `backtest_portfolio.py` | 保留原始回测结果，并计算扣除交易成本后的组合绩效 |
| `benchmark.py` | 使用 JQData 获取沪深300指数月末收盘价并保存为本地 CSV |
| `benchmark_analysis.py` | 基于策略与沪深300真实收盘价计算基准、超额收益、IR 与超额回撤 |
| `visualization.py` | 生成 IC、分组净值、组合净值和回撤图 |
| `main.py` | 一键运行数据获取、检查、处理、回测、成本模拟和基准分析 |

## 运行方式

### Windows + PyCharm 一键运行

1. 在 PyCharm 中打开项目文件夹 `C:\Users\Lenovo\Documents\Codex\2026-07-31\a-stock-multifactor`。
2. 点击 `File → Settings → Project → Python Interpreter`，选择你安装在 D 盘的 Python 解释器；不要使用 Codex 或系统中其他项目的解释器。
3. 打开 PyCharm 下方的 `Terminal`，确认终端位于项目根目录后执行：`python -m pip install -r requirements.txt`。
4. 将 `.env.example` 复制一份并重命名为 `.env`，填写你的 JQData 账号和密码。`.env` 仅保存在本机，不要上传到 GitHub。
5. 在 PyCharm 左侧文件栏右键点击 `main.py` 或 `run_all.py`，选择运行。
6. `main.py` 会依次执行数据获取、数据检查、清洗、因子处理、收益计算、IC 分析、分组回测、多因子回测、交易成本模拟、绘图和基准分析。如中途失败，会在控制台显示中文错误提示；请先解决错误，再重新运行。

所有模块均使用项目相对路径。即使 PyCharm 的解释器安装在 D 盘、项目位于 C 盘，只要运行 `run_all.py`，数据和结果都会保存到当前项目目录。

如果 JQData 控制台提示“账号权限仅能获取某个日期范围”，请打开 `data_fetch.py`，将 `DEFAULT_START_DATE` 和 `DEFAULT_END_DATE` 修改到提示范围内。日期边界必须严格包含在账号权限范围内，例如权限截止到 `2026-04-29` 时，不能填写 `2026-04-30`。

### 分模块运行

如需单独检查某一阶段，也可以按以下顺序运行：

1. `data_fetch.py`：下载原始数据；
2. `data_check.py`：检查原始数据质量；
3. `main.py`：执行完整研究流程，包括再次下载当前配置区间的原始数据。

主要结果会保存在：

- `data/processed/`：清洗后的数据、因子数据、收益数据和多因子得分；
- `outputs/`：IC 报告、分组回测结果、组合绩效指标；
- `outputs/tables/`：换手率、成本后绩效、基准比较与基准可得性说明；
- `outputs/charts/`：IC 曲线、五分组净值图、组合净值图和回撤图。

## 因子分析结果

当前试用权限覆盖的样本期较短，以下结论只用于描述本次样本内的初步现象：

- 营收增长率因子在五分组结果中表现较好，高分组相对低分组有更明显的收益区分；
- ROE 因子具有一定区分能力，尤其在高 ROE 股票组中观察到相对优势；
- EP 因子在当前样本期未体现稳定有效性，因此不应仅根据本次结果认定价值因子长期失效或人为调整其方向。

运行完成后，可优先在面试中展示以下文件和图表：

- `outputs/ic_report.csv`：三个因子的 IC 均值、IC 标准差、ICIR、正 IC 比例；
- `outputs/group_return.csv` 与 `outputs/charts/group_net_value.png`：单因子高分组是否优于低分组；
- `outputs/tables/portfolio_metrics_cost.csv`：计入简化交易成本后的组合绩效和平均月换手率；
- `outputs/tables/benchmark_compare.csv`：策略、沪深300基准、超额收益和超额回撤明细；
- `outputs/benchmark_report.txt`：策略、基准与超额收益的汇总指标；
- `outputs/charts/strategy_vs_hs300.png` 与 `outputs/charts/excess_return.png`：策略基准净值与累计超额收益曲线；
- `outputs/charts/portfolio_net_value.png` 与 `outputs/charts/portfolio_drawdown.png`：组合净值与风险表现。

请以实际运行得到的结果为准，不应在报告中预先编造收益率或 IC 数值。

## 风险与局限

- 样本周期受 JQData 试用权限限制，未覆盖完整市场周期，不能证明因子长期有效。
- 财务指标存在披露滞后、数据修订和口径差异；严谨实盘研究需要进一步按公告日核验。
- 本项目未覆盖极端市场环境，也未进行跨周期、跨市场状态的稳健性检验。
- 交易成本仅采用简化佣金模型，未加入停牌、涨跌停、冲击成本和容量约束。
- 本项目未做行业、市值中性化，因此部分收益可能来自风格暴露而非纯因子效果。
- 沪深300股票池偏向大盘股，结论不一定适用于全A市场。
- 回测结果仅是历史样本的模拟结果，不能代表未来收益，也不构成投资建议。
